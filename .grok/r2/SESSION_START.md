# Grok Session Start

## 必需输入

合法Art Task Packet必须给出：

- asset_id和类型；
- authority Section；
- 玩家可见描述；
- 必须/禁止表现；
- GM-only遮蔽约束；
- 纯2D技术与尺寸；
- 规则信号级别；
- 可访问性；
- 权利与安全要求；
- expected outputs。

缺失则返回 `BLOCKED_INPUT`。

- 完整Truth Bible；
- 全部战役种子；
- 未发现结局答案；
- 无关大区；
- 内部机械可靠状态；
- 其他玩家私有数据。
