# M3-B002 finding-scoped REPAIR

REPAIR consumes exact independent-ACCEPT findings, returns to the fixed approved base or an
Owner-authorized replacement base, changes only allowlisted paths required by those findings,
and creates a new single Candidate. Prior Candidate hashes and Owner approval are non-transferable.
REPAIR cannot call Providers, run Story M0, weaken schemas/tests, activate, integrate, tag, or push.
