# Change Control Gate

以下任一变化必须进入正式变更控制：

- 修改任何 `ACCEPTED` 决策；
- 改变平台与游戏边界；
- 改变权威裁定、随机、状态提交或可见性模型；
- 改变 Game Package ID、入口、兼容版本或许可证；
- 新增会影响玩家代理权、秘密隔离或持久化兼容性的规则；
- 将 P1/P2 功能提升到 P0；
- 删除或放宽 Tutorial/Golden 验收。

## 变更记录最低字段

1. 变更 ID 与申请人；
2. 原决策和拟议决策；
3. 影响的 Schema、脚本、场景、存档与平台接口；
4. 迁移和回滚方案；
5. 新增或更新的验收向量；
6. 项目所有者批准结果。

未经批准，不得通过实现先行的方式制造事实标准。
