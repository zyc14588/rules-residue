# Character Model Draft

## 方法值

- **解析** `analyze`：辨认模式、证据、规则和矛盾。
- **联结** `connect`：理解动机、建立信任、施加社会影响。
- **介入** `intervene`：直接改变环境、阻止威胁、执行精确操作。
- **承压** `endure`：抵抗异常、维持行动、承担后果。

P0 数值范围 0–3；创建角色时建议分配 `3, 2, 1, 1`。

## 熟练

P0 熟练按动作类型记录为 0–2，不建立庞大技能表。正式技能系统属于后续决策。

## 资源

- **洞见** `insight`：0–3。消耗 1 点可获得一次重投令牌或额外信息。
- **负荷** `strain`：0–6。付出代价或失败时上升；达到上限进入 `overloaded` 状态。

快速模式中，`overloaded` 不永久淘汰玩家。角色可以改为支援、接管临时角色或通过场景恢复继续参与。

## 状态

P0 只定义少量可机读状态：`focused`、`exposed`、`restricted`、`intent_shifted`、`overloaded`。状态必须有来源、范围、持续时间和解除条件。
