# Core Loop Draft

## 主循环

1. **探索**：玩家在持久开放世界中选择地点、路线或目标，而非被固定关卡链驱动。
2. **观察**：获取当前参与者可见的环境、事件、告示、NPC 行为和既有规则记录。
3. **提出假设**：将异常现象整理为一个或多个可检验的规则假设；假设必须标注置信度与证据来源。
4. **设计验证**：玩家决定遵守、观察、诱发、制造反例、比较不同对象或付出资源换取信息。
5. **陈述行动**：玩家使用自然语言描述目标、方法和愿意承担的代价。
6. **结构化与规划**：Agent/客户端产生 `StructuredAction`，Lua 决定检定、资源消费与规则交互边界。
7. **权威解析**：宿主提供随机或已批准资源操作，Lua 形成结果和 Typed Effects。
8. **更新知识**：事件可能提升/降低规则假设置信度，揭示作用域、触发、例外或优先级；只有权威事件能把假设升级为已确认事实。
9. **生存与利用**：玩家遵守、利用、绕过或破解已理解规则，换取位置、资源、同伴和真相碎片。
10. **世界持久化**：地点、规则域、NPC、威胁和已知规则写入存档并可在后续 Session 重访。
11. **长期推进**：跨区域事实进入“世界真相 / 元规则 / 归乡条件”调查链。

## 规则知识循环

```text
未知现象
 → 怀疑
 → 假设
 → 验证 / 反证
 → 部分确认
 → 确认作用域与条件
 → 找到例外或冲突
 → 利用 / 绕过 / 破解
 → 新异常 / 更高层规则
```

P0 不要求实现完整开放世界生成器，但 Tutorial 和 Golden 必须证明“离开规则域后知识与世界状态仍可保存”，并且场景结束不等同于 Campaign 结束。
