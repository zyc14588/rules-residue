# Naming Glossary

| 中文 | English | 状态 | 含义 |
|---|---|---|---|
| 规则残差 | Rules Residue | ACCEPTED | 项目正式名称；亦可作为世界内对异常规则遗留现象的工作术语 |
| 归途者 | Returner | PROVISIONAL | 被卷入异世界并寻找归乡路径的玩家角色统称 |
| 规则域 | Rule Domain | ACCEPTED | 一组具有明确作用范围、可与其他规则叠加的局部规则集合 |
| 规则假设 | Rule Hypothesis | ACCEPTED | 参与者基于证据形成但尚未成为权威事实的规则推断 |
| 规则事实 | Rule Fact | ACCEPTED | 经权威事件确认的规则知识，不等同于完整 keeper truth |
| 元规则 | Meta-rule | ACCEPTED-CONCEPT | 能解释/支配多个规则域的更高层规则；具体内容保持 GM-only |
| 洞见 | Insight | PROVISIONAL | 可用于重投或获取额外信息的稀有资源 |
| 负荷 | Strain | PROVISIONAL | 角色承受异常、压力与规则作用的通用资源 |
| 解析 | Analyze | PROVISIONAL | 识别模式、验证规则和处理复杂信息 |
| 联结 | Connect | PROVISIONAL | 影响 NPC、建立合作、组合分散线索 |
| 介入 | Intervene | PROVISIONAL | 主动改变对象、环境或规则状态 |
| 承压 | Endure | PROVISIONAL | 抵抗风险、异常和持续代价 |
