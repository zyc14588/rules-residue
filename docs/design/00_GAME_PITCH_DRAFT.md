# Game Pitch — 《规则残差》

> 类型与主题：ACCEPTED。具体世界来源、最终真相、归乡条件及大部分数值仍未冻结。

你不知道自己为什么来到这里。

道路会在没有人注视时改变方向；某些城镇要求“夜里听见敲门绝不能回答”，但下一条街的生存条件却可能要求你在第三次敲门时开门。废弃站台、无主聚落、森林、档案塔、移动集市和看似安全的城市都可能拥有自己的规则。更危险的是：**规则会叠加。** 同一地点可能同时受到区域规则、事件规则、物件规则、身份规则和某条更高层“元规则”的支配。

玩家扮演被卷入这个异世界的**归途者**。没有可靠的新手手册，也没人保证告示上的规则全部真实。你需要通过观察异常、交换情报、低风险试探、制造反例、追踪幸存者记录甚至主动触发危险来回答几个问题：

- 这条规则是真的吗？
- 它在什么范围内生效？
- 何时触发？
- 对谁有效？
- 有没有例外？
- 多条规则冲突时谁优先？
- 能否利用漏洞活下来？
- 能否彻底破解或改写它？
- 这条规则与“我们为什么在这里”有什么关系？

## 四层目标

### 1. 活着

饥饿、伤害、资源耗竭和怪异规则都会让探索具有成本。玩家首先需要度过当前风险，而不是等到所有谜题都有答案。

### 2. 破解规则

核心乐趣不是背诵规则清单，而是把未知规则从危险传闻转变为具有证据链的知识。错误假设也必须能产生真实后果。

### 3. 查清真相

每个规则域都可能提供局部解释和跨域线索。单一场景的真相不等同于整个世界的真相。

### 4. 回家

“回家”是长期战役方向，不是默认副本奖励。归乡条件需要通过跨区域探索、元规则发现与重大选择逐步建立。

## 世界结构

世界是持久开放的。玩家可以回到曾经探索过的地点，也可能发现旧地点因规则被破解、NPC 迁移、资源变化或更高层规则介入而发生变化。

无限流特征体现在：

- 不断出现新的规则域与异常组合；
- 区域之间存在进入/离开条件与跨域影响；
- 某些规则域具有明显“关卡感”，但仍属于同一持久世界；
- 规则可能被携带、感染、迁移或覆盖；
- 玩家逐步从局部规则推断更高层元规则。

具体世界起源、是否存在幕后组织、规则由谁制定、玩家为何被选中，均为后续 GM-only 设计，不在当前文档给出答案。
