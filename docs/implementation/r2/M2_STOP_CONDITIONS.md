# M2 停止条件

## 必须停止并阻塞

### 基线

- M1未独立验收通过或未在目标基线；
- 当前R2权威安装未PASS；
- 工作树不干净；
- Reading Map过期；
- TaskEnvelope、冻结摘要或候选绑定不一致。

### 设计

- 实现需要猜测延期项的生产语义；
- M1/平台与R2硬合同冲突且不存在包侧适配；
- 需要修改三分支、角色1死亡、道具本质或绝对红线；
- 发现六区观测最低条件在现行实现中无法表达。

### 范围

- 需要修改 `TRPG_PLATFORM`；
- OpenCode/Grok请求越过allowed_paths；
- 同一文件被两个并行任务认领；
- 实现者试图修改冻结计划或验收标准。

### 安全

- 任一环节命中绝对红线；
- 玩家/GM/机械层泄漏；
- AI可访问全种子或无关隐藏真相；
- 不可逆自然语言操作可能被含糊输入误触发。

### 质量

- 规则语义与Lua/表现不一致；
- 逻辑异常区没有不死人解；
- 发现完美逃课；
- 因果破产验证器无法区分仍可恢复状态；
- 确定性重放或构建失败；
- 独立验收环境无法执行强制测试。

## 允许的结果

```text
PASS
FAIL
BLOCKED_EXTERNAL
BLOCKED_ENVIRONMENT
BLOCKED_DESIGN_CONFLICT
```

不得用 `PARTIAL_PASS` 掩盖未完成的强制门禁。
