# Determinism and Security

## 禁止能力

`io`、`os`、`debug`、网络库、动态加载、任意 `load`、文件读取、环境变量、系统时钟和脚本随机均禁止。

## 允许能力

基础表、字符串、受限数学函数、宿主提供的只读上下文、纯函数模块与受控 Host Callback。任何 Callback 都必须有权限等级、输入 Schema、预算、审计事件和失败语义。

## 确定性

- 输入 JSON 先规范化；
- 数组顺序有语义，映射序列化采用稳定键顺序；
- 规则版本进入事件；
- 随机结果作为输入；
- 不依赖本地时区、浮点不稳定操作或遍历无序映射生成语义顺序；
- 包构建固定文件顺序、时间戳和权限。

## 失败处理

Lua 错误、预算超限、无效 Effect 或引用不存在对象时：不提交任何状态；写入受限诊断事件；生产错误信息不得包含秘密或完整上下文。
