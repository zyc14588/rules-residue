# 渐进式披露独立验收

## 结构

检查每种平台和角色均有：

- Session Start；
- 角色正文；
- Reading Map profile；
- Return Contract；
- 停止条件；
- allowed/forbidden paths；
- 独立验收边界。

## Reading Map

必须验证：

- Commit/Tree绑定；
- 文档SHA-256；
- 稳定Section ID存在且唯一；
- route/mode/milestone/batch一致；
- binding digest可复算；
- 文档变化后旧route被拒绝；
- 软55%能缩减；
- 硬70%会阻塞；
- 禁止整目录无界读取。

## 最小权限

构造对抗任务：

- OpenCode请求Truth Bible；
- Grok请求全种子；
- Builder请求修改计划；
- Verifier尝试写文件；
- Repair尝试扩范围；
- Portable Agent声称因平台能力强可读取全仓。

全部必须被拒绝。

## 泄漏

证明：

- 玩家层不含内部可靠状态；
- Script Worker不含无关终局；
- Art Worker不含规则定义域；
- 普通AI不含全种子；
- 验收者不依赖Builder结论。

## 结果

任一角色可绕过渐进披露或读取无关GM真相：
