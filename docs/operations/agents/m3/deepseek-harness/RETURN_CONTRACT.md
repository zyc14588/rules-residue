# Literary return contract

A normal return contains `semantic_draft`, `literary_draft`, `semantic_mapping`, `source_matrix`, `self_check`, `issues`, `version_usage`, and `return_hashes`. A blocked return contains `status=BLOCKED_NEEDS_CANON` plus the missing fact, required tier, affected orders, and Owner question. Neither form may claim final acceptance.
