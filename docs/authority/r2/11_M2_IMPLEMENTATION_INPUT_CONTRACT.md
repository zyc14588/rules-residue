# M2 完整技术垂直切片输入契约

## 目标

证明R2核心语义能够沿M1工程链真实运行：

```text
authoring
→ 规范化语义
→ Schema / fixture
→ OpenCode Lua
→ game-package runtime data
→ 主持工具调用
→ 玩家可见叙事
→ 审计事件
→ 自动验收
→ 确定性构建
```

M2不制作六个正式大区，不修改平台仓库，不声称完成正式发行。

## 垂直切片最小内容

- 角色1交付与沉浸式教程；
- 2—6人角色创建与纠缠因果抽取；
- 一个完整主要大区；
- 一个逻辑完全异常区；
- 主要纠缠观测、解决与永久稳定；
- 一件长规则装备；
- 一件短规则装备；
- 一条大区独特永久规则；
- 关键道具1/2型；
- 单人死亡与亡者视角；
- 亡者有限物理干预；
- 团灭、信息抽取、永久异常；
- 个人通用代价；
- 固定锚点、自建锚点、原初锚点；
- 一个代理Boss多阶段战斗；
- 分支1、分支2、分支3判定模拟；
- 2—6人、掉线、托管与回归名单测试。

## 实现优先级

1. 权威语义和Schema；
2. 固定种子和测试向量；
3. 规则/循环/可见性核心；
4. Lua脚本；
5. 2D占位资产与UI；
6. AI主持受约束表达；
7. 端到端与确定性构建；
8. 独立验收。

## 非目标

- 六个正式大区全内容；
- 正式最终Boss全部人格；
- 全量美术和语音；
- 正式数值平衡；
- 多语言内容；
- 平台级能力缺口的越权修复；
- 生产发布认证。

## 成功定义

```text
M2_INDEPENDENT_ACCEPTANCE=PASS
```
