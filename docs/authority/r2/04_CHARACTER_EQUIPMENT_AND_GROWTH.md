# 角色、装备、成长与信息结构

## 队伍

标准4人，支持2—6人。主线不得依赖固定职业或单一特殊天赋。人数变化通过并发目标、信息压力、行动经济和规则攻击面缩放。

## 角色创建

```text
现实背景
+ 核心专长
+ 社会关系
+ 生存短板
+ 抽取的纠缠因果
+ 可成长特殊天赋
```

纠缠因果必须同时包含可利用能力、特殊观察角度、实际风险和永久演化可能，不能只是随机诅咒。

## 能力

第一层处理常规行动：体能、感知、分析、交涉、技术、意志。

第二层处理规则交互：

- 规则校验；
- 判定干预；
- 代价识别；
- 信息收集；
- 权限伪装；
- 残差封装；
- 认知稳定；
- 因果追踪。

规则校验不是必选职业能力。

## 成长

本轮训练、普通增益、身份和常规物资重置。只有带永久前缀且有因果来源的对象跨循环：

- 永久成长；
- 永久装备；
- 大区独特规则；
- 永久阵营好感；
- 永久异常；
- 关键道具状态；
- 个人通用代价。

## 装备即规则

普通物资可以没有异常机械；任何正式登记为装备的对象必须是规则载体，包含：

```text
trigger
scope
conditions
effect
cost
duration
expiry
priority
collision
long_term_risk
persistence
```

### 长规则

语义条件、分支和多段效果更多，功能总量、可控性和组合上限更高。

### 短规则

断言少、条件少、执行直接，单位语义的权限密度与穿透力更高，但范围、次数或代价通常更苛刻。

判断依据是规范化语义结构，不是中文字符数。

## 信息不对称

信息按观察者分发。系统可记录“角色A声称看见X”，但不能自动证明其真实。关键主线必须有合作重建路径。

玩家现实记忆可直接指导行动，但不能自动成为NPC、机构、规则载体或终局承认的物理凭证。

## 亡者视角

死亡角色通过关键道具的因果系绳在有限物理范围内探索死亡因果层；不能直接对活人说话。支付生命、记忆、异常或其他规则承认代价后，可留下有限物理痕迹。

## 个人授权

个人通用代价与生命支付必须由对应玩家授权。代理、控制技能、队伍投票和AI不得伪造同意。

|---|---|---|---|
| `R2-D01` | `C` | 混合现实关系 | 主角团可由熟人、半熟人与陌生人混合组成，均来自现实层但不要求同一地点或时间。 |
| `R2-D02` | `C-R` | 标准四人支持二至六人 | 标准平衡队伍为4人，正式支持2—6人；主线不得依赖固定职业，人数缩放不能只改生命值。 |
| `R2-D03` | `C-R` | 进入时抽取纠缠因果 | 角色在世界碰撞中被波及时抽取一条纠缠因果，包含能力、弱点、规则响应和永久风险。 |
| `R2-D04` | `C` | 背景组合式角色创建 | 角色由现实背景、核心专长、社会关系、生存短板、初始纠缠因果与可成长特殊天赋组成，不设硬职业。 |
| `R2-D05` | `C-R` | 双层能力结构 | 第一层为常规行动能力；第二层覆盖规则校验、判定干预、代价识别、信息收集及可扩展规则交互能力。 |
| `R2-D06` | `C` | 永久前缀成长 | 基础角色恒定；本轮训练与普通增益重置；只有明确获得永久前缀且具因果来源的成长跨循环保留。 |
| `R2-D07` | `C-R` | 所有装备都是规则 | 正式装备均为可携带规则载体；规范化长规则功能总量与组合上限更高，短规则权限密度、直接性与穿透力更强。 |
| `R2-D08` | `B` | 通用代价个人持有 | 所有通用代价归个人，不设队伍公共池；转移和共同支付必须由明确规则与持有人自愿授权。 |
| `R2-D09` | `C` | 生命支付需本人授权 | 主动支付生命或个人代价必须由承担角色的玩家明确授权；多数表决、控制技能或代理不得伪造同意。 |
| `R2-D10` | `C` | 观察者分发信息 | 信息按实际观察来源分别交付，系统只记录角色声称看见什么，由玩家自行选择共享或隐瞒。 |
| `R2-D11` | `C` | 现实记忆可指导行动 | 玩家可依据现实记忆避险、输入密码或选择路线，但世界可要求物理证据、身份或权限才承认该知识。 |
| `R2-D12` | `C-DEFERRED` | 记忆主张机制 | 建立可登记、比较、关联和验证的记忆主张机制；可信度、隐私、AI处理与UI细节延后决定。 |
| `R2-D13` | `C-R` | 亡者因果系绳 | 亡者视角跟随关键道具行进，不能超出规定物理范围，也不能脱离队伍进行无风险全图侦察。 |
| `R2-D14` | `C` | 受控队内冲突 | 合作为默认；允许隐瞒、诱惑、误识与玩家选择的背叛。直接伤害、夺取代价或永久改变他人须预授权或由可追溯规则强制。 |
| `R2-D15` | `C` | 正式退场与世界内加入 | 退出玩家的旧角色正式永久死亡或离队；新角色通过世界内通道加入，获得阶段匹配基础能力与公开档案，不成为空降答案。 |
| `R2-D16` | `C` | 缺席协议 | 开团时选择锚点停留、受限代理、残响跟随或授权托管；未经本人授权不得消费永久资源、支付生命或做不可逆操作。 |
| `R2-D17` | `C` | 公开档案与私人记忆分离 | 新加入玩家获得队伍公开整理和稳定验证的信息，不自动获得私人幻觉、秘密、亡者视角与未共享现实记忆。 |
| `R2-D18` | `C` | 因果破产重开 | 因果破产后创建新战役；可复用角色概念和玩家现实知识，但不继承永久装备、代价、锚点、阵营关系、异常或关键道具状态。 |
