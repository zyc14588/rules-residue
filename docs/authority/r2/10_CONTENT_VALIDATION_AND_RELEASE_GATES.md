# 内容验证与发布门禁

## 三类验收

### 因果

- 规则定义域完整；
- 冲突与例外可复现；
- 死亡和结局可追溯；
- 跨循环变化有来源并可交叉验证；
- 开局固定答案未被修改。

### 玩法

- 正常路线、逃课路线与撤离路线可执行；
- 逃课具有不可忽略损失；
- 主线无永久软锁；
- 因果破产判断准确；
- 2—6人均有合法替代方案；
- 逻辑完全异常区有不死人解法。

### 表现

- 文本声部与发布者匹配；
- 玩家不可见结构未泄漏；
- 可访问性替代等价；
- 中文表现与规范语义一致；
- 美术和音频不暗示错误机械；
- 红线过滤逐环节执行。

## 单区完整验收

每个大区必须覆盖：

1. 初次进入；
2. 主要纠缠详细观测；
3. 普通高危路线；
4. 逻辑完全异常区明显警告与不死人解；
5. 至少一条逃课及其损失；
6. 纠缠解决；
7. 跨循环永久稳定；
8. 大区装备与永久化；
9. 大区独特规则；
10. 阵营关系；
11. 团灭、信息与重启；
12. Boss强度/人格/权限影响；
13. 2—6人缩放；
14. 地图技能差异；
15. 种子参数边界；
16. 红线与可访问性。

## 发布级端到端

至少运行：

- 常规调查战役；
- 极端逃课；
- 六区只观测的最高难度真结局；
- 多区解决后的低风险真结局；
- 先Boss后补课；
- 错误引爆灭世；
- 角色1死亡灭世；
- 强行跨界灭世；
- 因果破产；
- 重复送死与永久异常；
- 原种子重试；
- 真结局高资源新开局。

## 完美逃课失败条件

发现同时满足以下条件的稳定路线即FAIL：

```text
低风险
+ 低成本
+ 可重复
+ 大量跳过
+ 全部奖励
+ 不增Boss难度
+ 不缺真结局前置
```
