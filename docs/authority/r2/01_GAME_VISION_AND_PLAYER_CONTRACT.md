# 作品愿景与玩家契约

## 一句话定位

《规则残差》是一款支持2—6人、以4人队为标准的开放大陆规则怪谈TRPG。玩家作为被高维世界残片与现实碰撞意外卷入的普通人，在六个主要大区中调查条件化规则、利用规则残差、承担跨循环永久风险，最终尝试正确引爆由自身外部因果悖论制成的关键道具。

## 核心体验循环

```text
进入/重启
→ 观察规则载体与世界异常
→ 建立假设
→ 用实际行动承担风险进行验证
→ 战斗、交涉、绕路或利用规则
→ 获得信息、残差、装备、权限与代价
→ 详细观测或解决大区纠缠
→ 选择继续探索、逃课、挑战Boss或主动结束本轮
→ 团灭重启 / 世界毁灭 / 真结局回归
```

## 公平契约

### 因果公平

相同因果条件必须产生一致结果。所有死亡、长期后果、永久异常和结局必须由预先存在的规则解释。

### 不保证信息公平

主线危险可以只有弱提示、措辞差异、NPC习惯、环境异常或延迟显义的档案。玩家没有获得明显提示的权利。

### 例外

逻辑完全异常区必须明显警告、非主线必经并存在不死人解法；可能直接终止战役的世界级行为也必须有世界内清晰警告和动作契约。

## 开放世界承诺

- 不使用等级门、空气墙或固定章节顺序限制玩家。
- 地理可达不等于适合探索。
- 玩家可以强闯、死亡学习、发现漏洞并极端速通。
- 不存在低风险、低成本、全奖励、兼容真结局的完美逃课。
- 约2小时极端路线和约100小时全内容路线均为合法游玩范围。

## 叙事基调

世界严酷但不否定人性。队伍关系、可信NPC、文明残余和共同选择具有真实价值。黑色幽默与戏仿只作为少数局部声部，不取代严肃恐怖主调。

| `R2-A09` | `B` | 严酷恐怖中的稳定人性 | 世界残酷但队伍关系、可信NPC与共同选择具有真实价值；希望来自长期理解而非突然恩赐。 |
| `R2-A10` | `C` | 受控信息不对称 | 角色可因身份、能力、污染与死亡方式获得不同信息；主线真相必须能通过合作重建，关键证据存在可共享路径。 |
