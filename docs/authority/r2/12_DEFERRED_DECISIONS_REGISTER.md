# 延期事项登记

延期项不是OPEN顶层设计；其边界已冻结，具体参数须在指定阶段决定。

| ID | 事项 | 已冻结边界 | 最迟阶段 |
|---|---|---|---|
| `DEFER-R2-D12-001` | 记忆主张机制 | 必须能登记、比较、关联与验证；不能自动升级为世界真相 | 证据图/AI主持协议冻结前 |
| `DEFER-R2-E18-001` | 共同梦境演出细节 | 回归只为结局演出，无后日谈玩法与机械异常 | 终局内容制作前 |
| `DEFER-R2-H20-001` | 真结局高资源开局 | 仅真结局解锁有限元资源，不继承答案、永久规则或代价 | NG+/经济平衡前 |
| `DEFER-R2-C13-001` | 通用代价数值 | 个人持有、极稀有、超高难奖励、少量固定来源 | 数值平衡前 |
| `DEFER-R2-C14-001` | 豁免协议模板 | 每条规则独立协议，绝对规则可无普通豁免 | 规则引擎Schema冻结前 |

## 禁止默认假设

实现者不得以常见TRPG、常见RPG或平台现状为由自行决定延期项。需要临时fixture时必须：

- 标记 `TEST_ONLY_PLACEHOLDER`；
- 不进入正式内容；
- 不写入永久存档语义；
- 在验收中证明可替换；
- 指向延期ID。
