# R2 规范术语表

设计、Schema、Lua、测试和验收必须使用英文代码标识与中文规范名称。世界内可以使用地方称谓，但必须映射到下表。

| 中文规范术语 | 代码标识 | 定义 |
|---|---|---|
| 规则 | `RULE` | 世界或高权限载体可执行的条件化因果约束；不等同于世界内文字。 |
| 规则文本 | `RULE_TEXT` | 对规则的记录、解释、误导或高权限载体表现。 |
| 规则域 | `RULE_DOMAIN` | 一组在特定空间、时间、身份或状态下共同适用的规则范围。 |
| 规则残差 | `RULE_RESIDUE` | 旧规则或跨循环因果未被完全清除的残留。 |
| 逻辑完全异常区 | `LOGICALLY_ABNORMAL_ZONE` | 允许真正逻辑冲突的非主线高难区；必须明显警告且有不死人解。 |
| 部分高危碰撞区 | `PARTIAL_HIGH_RISK_COLLISION` | 规则域重叠但仍可用高层因果解释的高危区域。 |
| 主要纠缠 | `PRIMARY_ENTANGLEMENT` | 定义一个大区的外部世界轻度纠缠及本地影响。 |
| 详细观测 | `DETAILED_OBSERVATION` | 足以描述纠缠对象、表现、应对和终局关系的最低主线完成状态。 |
| 解决纠缠 | `ENTANGLEMENT_RESOLUTION` | 实际改变、稳定、切断、转移或治理主要纠缠。 |
| 永久稳定 | `PERMANENT_STABILIZATION` | 使大区主要安全状态和阵营好感跨重启继承。 |
| 纠缠因果 | `ENTANGLED_CAUSALITY` | 角色被世界碰撞波及时形成的能力、弱点与规则响应组合。 |
| 关键道具1型 | `CAUSAL_BOMB_TYPE_1` | 因果炸弹的观测与收束相。 |
| 关键道具2型 | `CAUSAL_BOMB_TYPE_2` | 因果炸弹的干涉与引爆相。 |
| 通用代价 | `UNIVERSAL_COST` | 个人持有的较小型扭曲因果具象物，用于高权限干预。 |
| 永久前缀 | `PERMANENT_PREFIX` | 声明对象可跨循环继承的机械标记，必须有因果来源。 |
| 永久异常 | `PERMANENT_ANOMALY` | TPK或高危行为产生、普通重启无法清除的跨循环异常。 |
| 因果锚点 | `CAUSAL_ANCHOR` | 世界承认主角团稳定存在过的重启定位。 |
| 原初锚点 | `ORIGINAL_ANCHOR` | 角色1交付关键道具之前的根锚点；选择它会使其他锚点失效。 |
| 因果破产 | `CAUSAL_BANKRUPTCY` | 所有合法恢复路线消失，当前战役不可恢复。 |
| 维护缺口 | `MAINTENANCE_GAP` | Boss被击败但关键道具未引爆时的世界持续恶化状态。 |
| 因果校准图 | `CAUSAL_CALIBRATION_GRAPH` | 用于终局的功能关系模型，不显示结局完成度。 |
| 已知信息记录 | `KNOWN_INFORMATION_REGISTER` | 记录来源、观察者与可信状态的信息主张集合。 |
| 记忆主张 | `MEMORY_CLAIM` | 玩家或角色对过去循环的可登记、可比较、可反驳陈述。 |
| 亡者视角 | `DECEASED_VIEW` | 死者受关键道具因果系绳限制的死亡因果观察层。 |
| 因果系绳 | `CAUSAL_TETHER` | 限制亡者活动范围并连接其与关键道具的关系。 |
| 大区独特规则 | `REGION_UNIQUE_RULE` | 解决大区主要纠缠后立即永久绑定的规则权益。 |
| 规则装备 | `RULE_EQUIPMENT` | 规范化语义可执行的可携带规则载体。 |
| 短规则 | `SHORT_RULE` | 少量断言、低条件、高权限密度的装备规则。 |
| 长规则 | `LONG_RULE` | 多条件、多分支、多段效果、高组合上限的装备规则。 |
| 战役种子清单 | `CAMPAIGN_SEED_MANIFEST` | 开局一次生成并固定的所有关键参数、映射与内容版本。 |
| 团灭重启 | `TPK_RESTART` | 分支1，处理循环结算而不结束战役。 |
| 灭世结局 | `WORLD_DESTRUCTION_ENDING` | 分支2，冻结当前因果链并结束战役。 |
| 共同梦境回归 | `SHARED_DREAM_RETURN` | 分支3，实际参与终局者以共同记忆回到现实。 |
