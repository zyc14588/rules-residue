# 最终Boss、终局判定与结局

## Boss战

Boss战是人格层、维护权限、战场规则、常规威胁、关键道具和大区结果共同组成的多阶段规则战。

“战胜”指取得最终节点控制权，可通过摧毁躯体、分离人格、夺取权限、冻结、谈判或阵营接管实现。

## 最低真结局资格

至少需要：

1. 六个大区主要纠缠全部详细观测；
2. 关键道具保持完整最终引爆能力；
3. 角色1存活并保持因果律武器功能；
4. Boss维护功能与扭曲部分可被正确分离；
5. 最终节点、权限与回归坐标有效。

解决大区不是绝对门票，但每解决一区都会降低Boss与终局判定难度。只观测六区的路线必须真实可行，同时是最高难度。

## 先Boss后补课

玩家可先战胜Boss并暂不引爆2型，再返回大陆补课。世界进入维护缺口，规则恶化、路线变化、Boss可能恢复。补课期间团灭会丢失控制权，但永久大区奖励保留。

## 终局动作

2型引爆必须由玩家完成明确的世界内最终动作。系统不弹二次确认，也不能提前显示将进入哪个结局。含糊讨论、假设和观察不得触发。

## 分支1：团灭重启

属于循环结算：

- 死亡因果；
- 一条加权关键信息；
- 永久异常；
- 自我了结累计；
- 道具反相；
- 重启干预；
- 锚点选择。

## 分支2：灭世

包括：

- 错误引爆2型；
- 角色1死亡；
- 强行进入其他世界；
- 少数明确世界级终止规则。

在世界接受灭世因果后，系统锁定因果链、剥夺玩家控制权、禁止代价、装备、亡者、锚点和主持修改，并进入结算。

## 分支3：共同梦境回归

终局多阶段判定完成后，Boss维护与扭曲分离，因果炸弹定向对消外部纠缠。Boss战入场时锁定的实际参与玩家角色进入回归候选，包括战中死亡后仍在操作亡者视角者。

现实只接纳为共同梦境；回归不保留机械异常，演出结束即游戏剧情结束。

## 终止链与战役谱系

灭世存档冻结并保留终止因果摘要。由终止链创建的新战役不继承机械状态。若同一谱系最终真结局，历次失败摘要作为参战履历公开。
