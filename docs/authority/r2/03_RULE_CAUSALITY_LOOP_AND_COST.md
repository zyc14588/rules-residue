# 规则、因果、循环与代价系统

## 规则本质

破损世界通过局部因果约束维持自身。规则不是任意命令清单，而是世界稳定、阵营治理、实体行为和高维残余技术的可执行约束。

绝大多数文本只是观察记录；少数高权限载体能够直接提交或修改局部约束。

## 规则层级

建议规范层级：

```text
WORLD
> CONTINENT
> REGION
> DOMAIN
> LOCATION
> ENTITY
> TEMPORARY
```

层级不是唯一冲突规则。更具体定义域、显式例外、权限载体和被世界承认的代价可形成局部覆盖。

## 规则残差

旧规则被删除、覆盖、失效、重启或互相碰撞后，可在以下载体留下因果残留：

- 空间与地理；
- 物体与装备；
- 记忆与语言；
- 人物习惯与身份；
- 关键道具；
- 锚点与循环；
- 阵营关系。

残差可以是证据、权限、漏洞、捷径或污染。

## 违规流程

```text
触发规则
→ 检查适用对象和定义域
→ 执行规则专属豁免协议
   ├─成功：避免、削弱、转移或推迟
   └─失败：即时效果 + 长期效果
→ 若最终造成团灭：进行永久异常概率结算
```

永久异常按因果来源附着在角色、队伍、关键道具或世界关系。普通重启不能清除。

## 验证规则

所有角色均可用实际行动侧面验证规则。验证必须承担风险，骰子决定执行质量、暴露、豁免和代价，不替玩家生成答案。

规则校验是可选天赋，可识别验证方案漏洞、载体权限和代价类型；支付代价后可安全验证，但不等于免费鉴定。

## 时间循环

默认TPK重启。单个死者进入受限亡者视角，不能直接与生者交流。循环处理：

1. 死亡因果与信息抽取；
2. 永久异常与自我了结累计；
3. 关键道具形态反相；
4. 通用代价干预；
5. 锚点选择；
6. 白名单状态继承；
7. 非永久状态重置。

## 锚点

- 默认选择最近有效锚点；
- 可选择原初锚点，但所有其他锚点失效；
- 固定锚点稀少并需条件激活；
- 高阶能力允许支付个人通用代价在任意合法地点自建锚点；
- 锚点不是快速传送点。

## 通用代价

通用代价是较小型扭曲因果具象物，完全归个人持有。主要来自超高难谜题、大区或阵营终局任务。极少数固定来源用于防止单次错误造成永久死锁，但不能无限保障刷死行为。

它可用于：

- 修正重启；
- 抵消永久异常；
- 安全验证；
- 建立锚点；
- 调整阵营关系；
- 补偿终局非核心误差。

不能替代真相、关键道具完整性、角色1存活或必要Boss处理。

## 因果破产

当所有合法恢复路线消失，存档进入因果破产并须重开。系统必须通过可达性与恢复能力验证器证明不可恢复，不能让玩家在伪可通关状态无限循环。

| `R2-B01` | `C` | 破损世界的局部约束 | 高维世界残片通过大量局部因果约束维持自身；许多荒诞规则实际承担稳定结构功能。 |
| `R2-B02` | `C` | 记录与权限载体并存 | 绝大多数规则文本只是观察记录；少数高权限载体能够提交约束并介入现实。 |
| `R2-B03` | `C` | 规则层级与局部例外 | 规则存在世界、大陆、区域、地点、实体、临时等层级；更具体规则与特殊代价可形成局部例外。 |

| `R2-B05` | `C` | 受约束的规则变化 | 规则可因世界事件、玩家行为和循环状态改变，但变化必须服从更高层规律并可追溯。 |
| `R2-B06` | `C` | 规则残差定义 | 规则变化、覆盖、失效或循环重置会在空间、物质、记忆、语言、人物、关键道具与循环中留下跨规则因果残留。 |
| `R2-B07` | `C` | 残差可利用 | 残差既是证据，也可成为装备、权限、身份、捷径、漏洞或污染；使用通常伴随风险。 |
| `R2-B08` | `C-R` | 违规豁免与双层后果 | 触犯规则先执行该规则的豁免协议；失败后同时产生即时效果与长期效果。团灭时概率抽取永久异常，支付通用代价或解决异常源才可抵消。 |
| `R2-B09` | `B` | 隐藏状态可调查 | 规则可针对玩家未知状态判定，但主线关键隐藏状态必须存在调查路径，不要求明显提示。 |

| `R2-B11` | `C-R` | 规则碰撞区分类 | 规则域碰撞区分逻辑完全异常区与部分高危区；解法有特殊需求，并允许世界内真实存在的逃课解。 |
| `R2-B12` | `C` | 真实漏洞型逃课 | 逃课解必须由世界预先存在的旧规则漏洞、身份、时间窗口、残差通道或规则抵消构成；循环只提高可发现性。 |
| `R2-B13` | `C-R` | 允许主线大逃课 | 玩家可大幅跳过大区乃至提前抵达或击败最终Boss；逃课会错过真结局前置，必须回头补齐。 |
| `R2-B14` | `C` | 极少数绝对规则 | 全作只有极少数真正绝对规则；其余规则通常存在定义域、条件或例外。 |

### 循环、死亡与代价

| 决策 | 选项 | 标题 | 权威陈述 |
|---|---|---|---|
| `R2-C01` | `C-R` | 可干预重启 | 全团死亡通常触发时间重启；通用代价可按支付量干预重启，最高可影响诡异阵营关系；最终Boss战和部分逻辑完全异常区也可改变结果。 |
| `R2-C02` | `C-R` | 亡者视角与生命代价 | 死亡角色不能直接与活人交流，但可在亡者视角探索隐藏信息；支付代价后可有限干预物理世界。生命可作为规则承认的高价值代价。 |
| `R2-C03` | `C-R` | 多锚点与原初回退 | 重启可选择最近有效锚点，或选择原初锚点；选择原初锚点后所有其他锚点失效并须重新激活。 |
| `R2-C04` | `C-R` | 玩家记忆不可强制遗忘 | 系统最多没收上一轮世界内记录或污染角色认知，不能要求真人玩家遗忘；玩家记忆与当前世界冲突可成为规则事件。 |
| `R2-C05` | `C-R` | 谨慎跨循环改变 | 宏观历史重置，但合法规则残差可造成跨循环改变；所有改变必须可交叉验证并有因果来源。 |
| `R2-C06` | `C-R` | 跨循环保留白名单 | 仅保留带永久前缀的项目、个人通用代价、关键道具以及玩家脑中的现实记忆；其他物资和记录默认重置。 |
| `R2-C07` | `C` | 双机制形态转换 | 关键道具可由主线核心事件从1型转2型；任何TPK令当前形态反相，从而允许错误时机获得2型。 |
| `R2-C08` | `A-R` | 因果炸弹两相 | 关键道具是外部因果悖论奇点经因果律武器制成的因果炸弹；1型观测与收束，2型干涉与引爆。提前错误使用2型会失去正确对消条件并导向灭世。 |
| `R2-C09` | `C` | 2型改变世界识别 | 提前持有2型会令规则域、旧设施、阵营和异常实体以不同方式识别主角团；它既是权限也是暴露面。 |
| `R2-C10` | `C` | 因果加权信息抽取 | 团灭后只抽取一个主要信息单元，由死亡原因、接触规则、未理解证据、区域、道具形态、既有信息、循环次数和主线缺口共同决定。 |
| `R2-C11` | `C-R` | 送死合法但可致因果破产 | 重复同类死亡仍可提高信息精度但边际收益下降，永久异常概率与强度持续增加；过度送死可使战役只能重开。 |
| `R2-C12` | `C` | 永久异常按因果附着 | 永久异常可附着于角色、队伍、关键道具或跨循环世界关系，载体由异常来源决定并必须记录。 |
| `R2-C13` | `C-R` | 通用代价本质与来源 | 通用代价是较小型扭曲因果具象物；主要来自超高难谜题、大区最终任务与阵营最终任务，并保留极少数固定获取途径防止永久死锁。 |
| `R2-C14` | `C` | 独立豁免协议 | 每条规则拥有自己的豁免协议；成功可避免、削弱或推迟后果。极少数绝对规则可以没有普通豁免。 |
| `R2-C15` | `A-R` | 允许主动自我了结 | 玩家可随时让角色自我了结，不提供菜单式安全重开；每次都会留下跨循环且逐步加重的负面影响，不得用于刷取通用代价。 |
| `R2-C16` | `A-R` | 正常无永久角色死亡 | 正常规则与Boss战不永久删除角色；永久死亡只用于长战役中玩家退出并换人时的正式退场。 |
