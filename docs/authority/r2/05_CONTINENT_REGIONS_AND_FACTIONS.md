# 大陆、大区、阵营与开放世界

## 顶层结构

```text
6个主要大区
+ 1个终局区
+ 网状道路与跨区规则碰撞
+ 每区至少1个逻辑完全异常区
```

终局区从早期可见和接近，不受等级门限制。

## 大区核心公式

```text
一种外部世界轻度纠缠
+ 一种本地文明生存/治理方式
+ 2—3种局部应对阵营
+ 一个主导声部与至少两个反向声部
+ 多条正常与逃课路线
+ 一条可永久绑定的大区独特规则
```

## 大区三阶段状态

### 已详细观测

掌握纠缠对象、表现、本地应对及其与最终节点关系。足以推进主线和满足六区最低观测要求，但重启后世界状态恢复。

### 已解决纠缠

实际切断、稳定、转移、抵消或治理纠缠，获得巨额奖励并削弱Boss。

### 已永久稳定

在解决基础上完成逻辑异常区、长期维护、代价或绑定条件，使主要安全状态与阵营好感跨循环继承。

## 逻辑完全异常区

每区至少一个。必须：

- 入口明显警告；
- 非主线必经；
- 存在不死人解法；
- 不要求随机试死；
- 可锁入且难以撤离；
- 是完整解决该区纠缠的前置之一；
- 提供高等级装备、通用代价、永久规则或重启干预奖励。

## 逃课

逃课是正式玩法，可以绕过区域Boss、登记、身份、路线乃至提前进入终局。每条逃课必须具有可审计损失，禁止完美解。

## 阵营

阵营是针对局部异常纠缠形成的应对方案，而非唯一真相代表。它们可提供终局功能替代，包括边界稳定、人格分离、权限与代价承载。

## 地图与移动

- 地图分地理、规则域、历史、阵营、锚点、残差、记忆主张层；
- 主持人有完整权威地图；
- 地图技能决定玩家记录精度；
- 快速移动使用交通、身份、阵营和规则捷径；
- 锚点不等于传送点。

## 其他世界边界

可观察投影、通信、物品和短暂重叠，但不得完整进入。强行越界使隔离层失效并直接进入灭世结局。
