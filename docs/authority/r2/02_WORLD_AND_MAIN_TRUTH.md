# 世界与主线真相

> 可见性：`AUTHOR / GM / MECHANICAL ONLY`。不得整体进入AI主持默认上下文或玩家运行时包。

## 世界本体

大陆是高维世界坍缩后遗留的维度残片。它已经形成真实居民、历史和文明，同时仍与现实及其他世界发生轻度或重度纠缠。

高维不是单纯力量等级，而是旧文明能够操作：

- 因果先后与承认；
- 规则权限与定义域；
- 历史分支与世界边界；
- 多个现实之间的纠缠；
- 结果是否被世界认定发生。

## 主角团

主角团不是命定者，只是被世界碰撞扫中的普通人。每名角色在进入时获得一条纠缠因果。外部因果身份使他们成为内部系统无法自行生成的修复变量。

## 角色1

角色1是高维幸存文明留下的因果律武器表现载体。它具有真实人格、记忆和情绪，但其使命优先级为：

1. 延续高维文明残余；
2. 修复世界碰撞损伤；
3. 切断与其他世界的异常纠缠；
4. 维持大陆文明；
5. 帮助主角团回到现实。

角色1可隐瞒、利用、牺牲或误导主角团，只要其行为可追溯到使命、权限、旧版知识或污染。角色1死亡立即触发灭世结局。

## 最终Boss

最终Boss是以下成分的聚合体：

- 失败路线的历代主角团；
- 历代牺牲者；
- 负责封印的高维幸存者或维护人格；
- 最终扭曲因果节点。

Boss既是灾难源，也是濒临崩溃系统的稳定者。它必须被战胜，但仅摧毁其躯体不足以完成修复；真结局要求分离维护职责和扭曲部分。

## 关键道具

主角团外部因果与大陆碰撞形成悖论奇点。角色1所代表的因果律武器将其捕获、约束并具象为因果炸弹：

- **1型**：观测、收束、记录、校准；
- **2型**：干涉、解锁、引爆、对消。

正确使用时，2型定向否定大陆与外部世界之间的异常纠缠；错误使用时，它会将整个大陆判定为悖论并摧毁世界。

## 三分支骨架

```text
角色1交付1型
→ 六区探索、解密、战斗与校准
→ 1型转2型
→ 最终Boss
   ├─团灭：抽取信息、道具反相、重启
   ├─错误引爆/角色1死亡/跨界：灭世结算
   └─满足最低资格并通过终局判定：循环终结，共同梦境回归
```

## 共同梦境

大陆真实存在，但现实无法接纳一条正常客观历史来证明经历。回归者共享核心事实，各自保留私人视角差异；回归后没有可继续使用的异常能力或后日谈玩法。
