# 02 — Product Scope P0

P0 只交付一条严格可验收的**规则怪谈开放探索**垂直闭环，而不是一次性实现整个异世界。

## P0 进入项

- “无限流 × 规则怪谈 × 异世界开放世界”的正式产品定位；
- 一个最小、可持久的规则域模型；
- 规则的发现、假设、验证、确认、利用/绕过/破解语义；
- 规则作用域、触发条件、例外、优先级和冲突必须可由数据表达；
- 一个可序列化角色模型；
- 四项方法值、四档结果的通用检定（数值仍为 PROVISIONAL）；
- 调查、影响、介入、协助、稳定与消耗洞见动作；
- 洞见与负荷资源；
- 生存压力、关键路径失败推进与可错过秘密；
- NPC 意图改变的规则化效果；
- Human GM、AI GM、Human Player、AI Player 身份与权限合同；
- 世界真相、参与者知识、规则假设、Agent 记忆与摘要分离；
- Tutorial《零号站台》与 Golden《第五份记录》两个原创规则域验证场景；
- 标准包、锁文件、静态安全检查和确定性构建；
- Codex 规划/验收、OpenCode 脚本、Grok 美术的混合开发 Task Packet 合同。

## P0 不进入项

完整清单以 `governance/scope.json` 为准。尤其不进入：平台施工、第三方规则兼容、完整开放世界地图、完整战斗、正式美术全集、语音、多模态必需流程、大规模长期战役、最终世界真相、最终归乡路线、市场与商业化。

## Scope Gate

新增需求只有满足以下全部条件才能进入 P0：

1. 对“发现规则 → 验证 → 破解/利用 → 生存推进”闭环不可缺少；
2. 能由 Tutorial 或 Golden 验证；
3. 不要求平台特权；
4. 不引入第三方 IP；
5. 有 Schema、迁移和回滚边界；
6. 不破坏确定性、回放、秘密隔离或 AI 权限；
7. 若由 OpenCode/Grok 执行，必须能封装为 Task Packet 并由 Codex 独立验收。
