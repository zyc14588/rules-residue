# 10 — Open Decisions

机器权威清单位于 `governance/decisions.json`，本文件提供解释。

## 必须由项目所有者决定

- 最终许可证与商业权利安排；
- 正式世界观、年代、组织和长期战役结构；
- 角色成长、创伤、退场与替换；
- 控制类效果作用于真人控制角色时，超过 P0“下一次单一行动”的对抗、解除、展示和长期边界；
- 正式美术、音频、本地化和素材来源流程。

## 依赖平台决定

- 正式 Game Package API 版本；
- Creator Tool 往返规范；
- Lua 5.5 沙箱宿主 API、预算和错误码；
- 存档迁移与包升级接口；
- AI Runtime 工具调用和可见性投影格式。

## 实现纪律

在这些决定关闭前，只能使用显式草案字段与适配层。不得将临时名称、数值或接口写成不可迁移的永久格式。
