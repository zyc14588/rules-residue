# 10 — Open Decisions

机器权威清单位于 `governance/decisions.json`，本文件提供解释。

## 必须由项目所有者决定

- 最终许可证与商业权利安排；
- R2 deferred register 仍未决的具体六区主题、Boss 人格名单、数值和算法；
- 角色成长、创伤、退场与替换；
- 控制类效果作用于真人控制角色时，超过 P0“下一次单一行动”的对抗、解除、展示和长期边界；
- 正式美术、音频、本地化和素材来源流程。

## 依赖平台决定

- 正式 Game Package API 版本；
- Creator Tool 往返规范；
- Lua 5.5 沙箱宿主 API、预算和错误码；
- 存档迁移与包升级接口；
- AI Runtime 工具调用和可见性投影格式。

## 实现纪律

在这些决定关闭前，只能使用显式草案字段与适配层。不得将临时名称、数值或接口写成不可迁移的永久格式。

## M1 OPEN 已被 R2 取代

`RR-O003` 所合并登记的世界/规则/无限流来源与归乡条件已是 `SUPERSEDED_BY_R2`，不再是 ACTIVE `OPEN`。高维坍缩残片、多世界因果纠缠、角色1、聚合 Boss、因果炸弹、错误/正确引爆与共同梦境回归以 R2 权威为唯一 ACTIVE 来源。
