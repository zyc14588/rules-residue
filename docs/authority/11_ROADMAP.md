# 11 — Roadmap

## M0 — Project Initialization（本包）

独立边界、治理、P0、最小规则、两个场景、Schema、Lua 合同、验证与打包。

## M1 — Platform Contract Alignment

在 TRPG_PLATFORM 正式 Game Package API 上执行四个入口；完成沙箱、事务、回放、存档和兼容错误测试。

## M2 — Playable Vertical Slice

关闭核心世界观、角色、成长与控制效果决策；完成 60–120 分钟可玩的 Tutorial，并通过 Human/AI GM 与 Human/AI Player 组合测试。

## M3 — Creator Roundtrip and Multiplayer

完成 Creator Tool 双向同步、多人断线恢复、快速模式不淘汰和完整 Golden 回归。

## M4 — Content and Release Governance

完成许可证、原创素材证据、正式本地化、安全审计与发布候选。

## M5 — First Public Release

只在所有 public_release gates PASS 后进入。
