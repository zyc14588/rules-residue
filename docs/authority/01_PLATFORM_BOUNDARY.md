# 01 — Platform Boundary

## 平台职责

TRPG_PLATFORM 负责：身份、房间、Campaign/Session 生命周期、多人连接、权限、Lua VM、随机数、权威事务、事件日志、数据库、存档、AI Runtime、RAG 基础设施、Creator Tool、部署与运维。

## 游戏职责

《规则残差》负责：角色字段、动作类型、难度、检定结果、游戏资源、状态、场景、NPC、线索、威胁、结局、游戏级可见性标签、Agent 可用工具语义和叙事事实模板。

## 禁止耦合

平台代码不得：

- 识别或分支处理《规则残差》的 package ID；
- 硬编码本游戏属性、资源、状态或场景；
- 用平台管理员权限重写骰子结果或已提交游戏历史；
- 让 AI 服务直接写游戏状态；
- 为官方包开放第三方包不可用的隐藏 API。

本项目不得：

- 直接访问平台数据库、消息总线、文件系统或网络；
- 假定单一 AI 供应商或模型；
- 保存 API Key；
- 把平台用户、认证或网络协议复制进游戏包；
- 依赖未声明的宿主全局变量。

## 集成失败原则

平台接口缺失或不兼容时，Game Package 必须 fail closed：拒绝启动并输出机器可读兼容错误，不得降级为绕过权威事务的本地执行。
