# Grok Visual Order System

```text
AUTHORITY_SCOPE = CONSTRUCTION_GOVERNANCE_ONLY
R2_CANON_PRECEDENCE = HIGHER
```

A validated Visual Order Package is Grok's only formal production authority. A raw art request or legacy art prompt is not an order.

The package includes semantic composition proof, Canon and Dossier references, must/forbidden objects, spatial relations, salience, occlusion, state continuity, Reveal references, an equivalent accessible description, rights/provenance, and a truthful capability declaration.

Grok cannot define rules, story truth, puzzle answers, mechanical values, or map topology. Visual output is a candidate until Codex cross-modal validation, provenance checks, and required Owner approval. This installation does not invoke Grok.
