# DeepSeek Harness Text Order System

```text
AUTHORITY_SCOPE = CONSTRUCTION_GOVERNANCE_ONLY
R2_CANON_PRECEDENCE = HIGHER
```

Only a validated Text Order Package may authorize literary work. The controlled pipeline is Coordinator → Semantic Implementer → Literary Writer → Independent Checker → Defect Router → at most two targeted Repair passes.

Every return contains a Semantic Draft, Literary Draft, semantic mapping, Canon/Reveal source matrix, self-check, issues, version usage, and return hashes. Missing Canon yields `BLOCKED_NEEDS_CANON` with the missing fact/tier/impact; unaffected orders may continue.

DeepSeek Harness cannot create T1/T2/C1, modify authority, persist state, modify runtime, Lua, or Game Package inputs, or form final PASS. Its output stays under the controlled literary return namespace until Codex validation and approvals. This installation does not invoke DeepSeek.
