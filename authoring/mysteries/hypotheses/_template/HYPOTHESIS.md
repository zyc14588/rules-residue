# Hypothesis 模板

```yaml
hypothesis_id: hypothesis.<slug>
status: proposed # proposed | testing | supported | refuted | superseded
proposed_by: ""
statement: ""
subject_refs: []
supporting_clues: []
counter_clues: []
tests: []
known_exceptions: []
supersedes: []
visibility: public
runtime_confirmation_event: null
```

`supported` 仍不是跨世界真相状态。只有权威运行事件可以把允许的知识标记为 confirmed；Hypothesis 永远不能反向覆盖 Truth Bible。
