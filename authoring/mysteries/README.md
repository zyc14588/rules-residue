# Mystery Authoring

Clue、Hypothesis 与 Revelation 是三个不同对象：

- Clue 是可获得、可追溯的证据或报告；
- Hypothesis 是参与者或 NPC 的可验证主张；
- Revelation 是满足条件后把最小必要事实投影给指定受众的过程。
