# Character, Faction and Entity Authoring

NPC、Faction 与 Entity 都必须分离以下信息域：公开事实、真实事实、其自身认知、错误认知、所知规则、关系和可见性。真实事实不得因为写在角色文件中就自动进入玩家或 Agent 上下文。
