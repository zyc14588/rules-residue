# Return Home Arc — AUTHOR / GM ONLY

本节保留 `SUPERSEDED_BY_R2` 的 M1 历史槽位。归乡的冻结最低资格与三分支见后续 R2 ACTIVE 章节。

## 阶段槽位

这些槽位描述依赖类型，不规定唯一顺序、地点或答案：

1. `orientation`：确认“离开局部 Rule Domain”与“返回原世界”不同；
2. `cross_domain_evidence`：从多个持久 Region 获得可互证信息；
3. `candidate_models`：形成一个或多个可反驳的归乡假设；
4. `route_validation`：验证候选路线的条件、代价、例外和冲突；
5. `commitment`：在已确认信息允许时作出选择并承担持久后果；
6. `aftermath`：记录结果对世界、角色和未完成谜题的影响。

阶段可以并行、回退或被世界状态重新打开，不构成固定章节链。

# Return Home Arc

## 阶段

### 求生期

角色1交付1型，队伍确认循环、规则域、死亡与记录重置。

### 建模期

完成六区主要纠缠观测，逐步理解高维残片、角色1、Boss和关键道具。

### 干预期

选择解决大区、永久稳定、阵营协作、获取权限、通用代价和Boss削弱。

### 终局期

战胜Boss、分离维护与扭曲、校准2型、锁定回归名单并执行引爆。

## 最低资格

```text
6/6主要纠缠详细观测
+ 关键道具完整
+ 角色1存活且功能有效
+ Boss维护/扭曲可分离
+ 回归坐标与基础权限
```

不得向玩家显示普通任务清单或百分比。功能性诊断可以提示无法闭合的因果问题。

## 失败分支

- 团灭：循环结算并重启；
- 错误引爆：世界毁灭；
- 角色1死亡：世界毁灭；
- 强行跨界：世界毁灭；
- 因果破产：明确告知当前战役不可恢复并重开。

## 回归

Boss战入场时锁定的实际操作者进入回归候选。成功后只播放共同梦境结局与参战履历，不提供现实后日谈玩法。
